# Generalized Anomaly Detection using Autoencoders

## 📌 Overview
This project implements a generalized anomaly detection system for tabular datasets using an Autoencoder built with TensorFlow/Keras. Users can upload CSV datasets, automatically preprocess the data, and identify anomalous records through reconstruction error.

---

## 🚀 Features
- Upload and analyze any CSV dataset
- Automatic data preprocessing and normalization
- Handles missing values and categorical features
- Autoencoder-based anomaly detection
- Interactive visualization of anomalous records
- Reconstruction error analysis

---

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

---

## 📂 Input
CSV files containing tabular data.

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
python generalized_anomaly_detection.py
```

---

## 📈 Output
- Detected anomalies
- Reconstruction error visualization
- Summary of anomalous records
